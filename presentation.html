Engineering & Design

Technology Stack & Visual Identity

Clean, dependable medical software designed to run effortlessly in VS Code.

05

🎨 Blue & White Clinical Theme

Meticulously crafted color scheme using Deep Navy (#08213b), Medical Sky Blue (#0284c7), and crisp White. Evokes calmness, precision, and sterile clinical authority.

⚡ Zero-Dependency VS Code Execution

Built with vanilla HTML5, modern CSS3, and ES6 JavaScript. Includes a lightweight, pure Node.js HTTP server (server.js) that launches in seconds without running npm install.

💾 LocalStorage Persistence

Patient bookings, status changes, and activity audit logs persist automatically in the browser. Pre-seeded with realistic sample records (MC-1001 to MC-1005) for immediate demo testing.

🖨️ Print-Ready Medical Pass

Features dedicated @media print CSS styling that automatically strips navigation bars and banners, outputting a clean, professional OPD patient slip on paper or PDF.
